# Runbook: Corporate Password Reset

**Document ID:** KB-IT-002  
**Category:** Identity and Access  
**Audience:** L1 IT Service Desk  
**Version:** 1.0  
**Status:** Approved for this synthetic project

## Symptoms

- The user has forgotten their corporate password.
- The user cannot authenticate to company applications.
- The user needs to update credentials after a password change.

## Troubleshooting Procedure

1. Confirm which company application or service the user is trying to access.
2. Direct the user to the organization's approved password-reset portal.
3. Ask the user to follow the identity verification steps displayed by the portal.
4. If a password reset succeeds, ask the user to retry authentication with the updated credentials.
5. If authentication still fails, record the application name and exact error message.
6. Escalate persistent authentication failures to the identity and access management team.

## Security Notes

- Never ask the user to disclose their password or one-time verification code.
- Do not bypass identity verification.
- Do not reset another person's password without an authorized process.

## Escalation Criteria

Escalate if the reset portal is unavailable, identity verification fails repeatedly, or the account appears locked or disabled.

This is synthetic training content. It does not specify a real organization's password-reset URL or identity verification procedure.
