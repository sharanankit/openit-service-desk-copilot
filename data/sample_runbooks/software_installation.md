# Runbook: Software Installation Request

**Document ID:** KB-IT-003  
**Category:** Endpoint Support  
**Audience:** L1 IT Service Desk  
**Version:** 1.0  
**Status:** Approved for this synthetic project

## Symptoms

- A user cannot install an application.
- The installation requests administrator privileges.
- The user needs access to software that is not currently installed.

## Troubleshooting Procedure

1. Confirm the application name, version, and business purpose.
2. Check whether the application is available through the organization's approved software catalog.
3. If approval is required, direct the user to the documented software request process.
4. Confirm that the device meets the application's documented requirements.
5. If installation fails, capture the exact error message and relevant timestamps.
6. Escalate administrator-privilege issues or installation failures to endpoint support.

## Security Notes

- Do not instruct users to bypass endpoint security controls.
- Do not share administrator credentials.
- Do not recommend unapproved software downloads.

## Escalation Criteria

Escalate when the application is absent from the approved catalog, an approval is pending, administrator privileges are required, or installation fails after approved checks.

## Source Limitations

This is synthetic training content. It does not represent a real organization's software catalog or approval process.
